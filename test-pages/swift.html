Swift Concurrency

Actors

Actors protect their mutable state and prevent conflicting access to that state in concurrent code. An actor is a reference type that serializes access to its mutable state.

Async/Await

Swift's async/await syntax provides a readable way to write asynchronous code. Functions marked with async can suspend execution and resume later.

Structured Concurrency

Structured concurrency ensures that concurrent tasks have a well-defined lifetime and scope. Task groups allow you to manage multiple concurrent operations.

Sendable

The Sendable protocol indicates that a type can safely be transferred across concurrency domains. Value types are generally Sendable by default.

MainActor

MainActor is a global actor that represents the main dispatch queue. UI updates must happen on the MainActor.
