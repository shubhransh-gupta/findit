Actor Isolation in Swift

Actor isolation is a fundamental concept in Swift's concurrency model. Each actor maintains its own isolated state that can only be accessed through the actor's executor.

Isolated State

Properties and methods of an actor are isolated by default. External code must use await to access actor-isolated members, ensuring thread-safe access.

Nonisolated Members

Members marked as nonisolated can be accessed synchronously from any context. This is useful for computed properties that don't access mutable state.

Global Actors

Custom global actors allow you to define shared isolation domains beyond the default actor isolation. The @MainActor attribute is the most commonly used global actor.
